# DatenJäger 2.1.3

Esta versión mejora el uso cotidiano de la aplicación de escritorio y el cambio entre proveedores del asistente. Incluye instaladores para Windows y Linux con el backend Python integrado.

## Lo nuevo y lo corregido

- **Interfaz más clara:** bienvenida, acceso, registro, Inicio, Ajustes y Conexión de modelos reorganizados con menos tarjetas anidadas, más espacio y separadores discretos. Se conservaron los temas claro/oscuro, las fuentes, los colores y las animaciones existentes.
- **Conexiones de IA independientes:** Gemini, NVIDIA NIM, OpenAI, OpenRouter y servicios compatibles pueden mantener cada uno su credencial, modelo y endpoint. Cambiar de conexión activa el perfil elegido sin reiniciar y no borra las demás claves. El asistente usa el protocolo y el endpoint del proveedor activo.
- **Configuración más segura al editar:** el sondeo del estado ya no revierte un proveedor seleccionado ni sobreescribe el modelo o endpoint pendientes. Mientras hay cambios sin guardar, se impide probar o eliminar por accidente la conexión anterior. La interfaz no recupera las claves guardadas del backend.
- **Arranque más fiable:** corregido el fallo intermitente que impedía iniciar el servicio local cuando su token comenzaba por un guion.
- **Documentación al día:** README con capturas reales hechas sobre datos de prueba, badges de arquitectura y agradecimientos; retirados los HTML de mockups ya utilizados, conservando sus imágenes y guías de diseño. Los HTML se pueden recuperar desde el historial de Git.

## Distribución y comprobaciones

Se publican **dos instaladores adjuntos**: un `.exe` para Windows y un `.AppImage` para Linux. El instalador no contiene la base de datos ni credenciales del usuario; estos datos permanecen en el almacenamiento local de cada instalación. El `.exe` no está firmado digitalmente, por lo que Windows puede mostrar SmartScreen.

Antes de publicar se verificaron localmente 264 pruebas Python, 8 pruebas Node, el build del frontend, el recorrido de la aplicación Electron con datos aislados y el arranque del backend con un token de prueba que empezaba por guion. Las pruebas de proveedores usan claves sintéticas: **no certifican acceso real, cuota ni generación en NVIDIA u otros servicios externos**. Los modelos locales siguen fuera de este alcance.
